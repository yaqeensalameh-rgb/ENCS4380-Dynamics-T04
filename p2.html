HOMEWORK 2 · MODULE P2

A Slow Sensor in the Loop

The controller can only control what the sensor reports, not the true output. A slow sensor (time constant τs) delays that report. Increase τs and watch the true output overshoot, then oscillate.

01 · SETUP

Plant, Sensor and Controller

Plant: G(s) = K/(τs+1) · Sensor: H(s) = 1/(τs·s+1) · Control: u = Kp·e + Ki·∫e − Kd·dys/dt, where e = r − ys (ys = sensor reading).
